- 计算功能与三栏工作区保持原版使用路径，并使用原生 C++ 计算引擎重做桌面端。

HTML 版本：`Gi DMG v2.1.9.html` 继续作为浏览器版参考。

EXE 版本（v2.2.0）的实现：

1. 不再将 HTML 打包进 EXE，也不使用 Electron、WebView、浏览器内核、CDN 或运行时服务器；窗口和控件由 Win32/GDI 原生创建。
2. 启动进入配置管理界面，可以打开 date 文件夹中的配置，也可以新建配置。
3. 配置、全局设置、角色面板、伤害来源、基准和历史摘要自动保存到 EXE 同目录的 `date` 文件夹。
4. 进入配置后保留左侧导航、中央编辑区和右侧伤害统计，并在中央顶部新增原生“灵动岛”操作条，提供保存并退出、不保存、快速拉表、设置。
5. 原右上角工具改为原生按钮，保留导入、导出、公式、面板明细、伤害占比和更多操作入口。
6. 发布文件名为 `Gi DMG [ver.].exe`，Windows 构建脚本位于 `native/build.ps1`，目标输出为 `exe_bin/Gi DMG v2.2.0.exe`。
